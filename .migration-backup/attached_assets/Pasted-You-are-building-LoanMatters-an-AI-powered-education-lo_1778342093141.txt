You are building LoanMatters — an AI-powered education loan comparison platform for Indian STEM students planning to study abroad (US, UK, Canada, Germany, Australia). The live site is at https://loan-matters.vercel.app/. Stack: Next.js 14 (App Router) + Tailwind CSS on the frontend, Node.js/Express for the backend API, PostgreSQL via Supabase for data, and a separate PHP 8+ admin panel for blog management.
Core brand values:

We never sell user data. We never spam. We just compare.
Faster, cleaner, more honest than BankBazaar or Paisabazaar.
Niche: education loans for abroad studies — go deep, not broad.

Stack constraints:

Frontend: Next.js 14, App Router, Tailwind CSS, TypeScript
Backend API: Node.js + Express (deployed on Railway)
Database: Supabase (PostgreSQL)
Admin panel: PHP 8 + MySQL (deployed on Hostinger or any VPS)
Rate updates: Vercel Cron Jobs (every 6 hours)
No .env file to be created or overwritten — use .env.example only

1. Enable SSR on all key pages.
In app/page.tsx (homepage), switch from a client component to a server component. Fetch loan data from Supabase directly in the server component:
typescript// app/page.tsx
import { createClient } from '@supabase/supabase-js'

const supabase = createClient(
  process.env.NEXT_PUBLIC_SUPABASE_URL!,
  process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!
)

export const revalidate = 21600 // revalidate every 6 hours (ISR)

export default async function HomePage() {
  const { data: loans } = await supabase
    .from('loans')
    .select('*')
    .order('interest_rate_min', { ascending: true })

  return <LoanListClient loans={loans ?? []} />
}
